# JLPT N1 單字・文法

一份單檔 HTML 製作的 JLPT N1 學習應用，收錄 N1 常考單字與文法句型，皆附例句、假名讀音、中文翻譯，並支援 Web Speech API 發音朗讀。做法沿用同專案的 `ch2`（單檔、資料內嵌於 `<script>`、卡片式呈現、發音播放）。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用，無需安裝或建置。

若瀏覽器對 `file://` 開啟的頁面有語音（Web Speech API）限制，可改用簡易伺服器開啟：

```bash
python3 -m http.server
```

再以瀏覽器造訪 `http://localhost:8000`。

## 內容結構

分為兩個 tab：

- **單字**：約 430 個 N1 高頻單字，依類別分組（抽象概念、社會經濟政治、心理態度人際、動詞、複合動詞、い／な形容詞、副詞連語、外來語、四字熟語慣用句、補充）。每張卡片含 單字／假名／羅馬拼音／中文／例句（日＋假名＋中譯）。
- **文法**：約 160 個 N1 文法句型，依機能分組（時間契機、原因理由、逆接讓步、附加並列、限定極限、強調感情、評價立場、目的手段、話題關聯、樣態推量、敬語慣用文末）。每張卡片含 文型／接続／意味／例文（日＋假名＋中譯）。

所有資料以 `DATA` 物件內嵌於 `index.html` 的 `<script>` 區塊中（`vocab` 與 `grammar` 兩個鍵）。

## 播放功能

- 點擊單字／文型 → 播放該字或該例句。
- 各類別「全部播放例句（中→日）」：每則例句先唸中文翻譯、再唸日文。
- 單字 tab「播放中日」：每個單字先唸日文、再唸中文意思。
- 文法 tab「全部播放例句（日）」：只唸日文例句，供聽力練習。
- 連續播放每則之間停頓約 0.8 秒。
