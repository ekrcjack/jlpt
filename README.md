# 日本語學習 ｜ JLPT 單字・文法・發音

一組獨立、單檔的 HTML 日語學習應用，依 JLPT 程度串成一個總覽首頁。無需安裝或建置，直接用瀏覽器開啟即可；每個項目皆附例句、假名讀音、中文翻譯與 Web Speech API 發音朗讀。

## 線上瀏覽

首頁（`index.html`）以卡片連結到各程度的學習頁：

- **N5** — `ch2/`：單字漢字發音（五十音、必背單字、漢字、動詞、形容詞）
- **N4** — `n4/`：單字 386＋文法 118
- **N3** — `n3/`：單字 377＋文法 150
- **N2** — `n2/`：單字 400＋文法 147
- **N1** — `n1/`：單字 430＋文法 160

N5 補充教材・工具：

- **N5 完整學習筆記** — `fulln5/`：五十音、單字、漢字、文法、動詞變化、聽力、模擬試題、進度表
- **N5 單字卡** — `jn5/`：翻卡式單字卡（分類、發音）
- **N5 單字卡（變體版）** — `yuann5/`：單字卡的另一個版本
- **常用漢字 2,136 字** — `han/`：可搜尋瀏覽的常用漢字一覽表
- **JLPT 單字例句** — `n1-n5voc/`：N1〜N5 約 7,900 字，五十音順並附例句

文法專題：

- **日本語文型帳** — `pat/`：112 個句型分 12 類，每型 3 例句
- **助詞大全** — `part/`：29 個助詞分四類，每個 5 例句
- **て形の変化規則** — `te/`：103 個動詞依三類分組的て形對照
- **い形容詞・な形容詞** — `adj/`：44 個形容詞的活用、反義對照與練習
- **日文連結詞 15 個** — `connecting/`：でも・けど・だから 等接續詞與逐句解析
- **四態變化對照表** — `four/`：現在／過去 × 肯定／否定四格對照，39 組 156 句

會話・課程筆記・例句：

- **生活日語會話** — `con/`：23 單元 219 場景 568 句對話，附 N4 文法解析
- **日文文法與單字筆記** — `udemy/`：Udemy 課程整理，133 課依 10 個文法主題分頁
- **日文例句整理** — `sentences/`：150 課共 2,258 例句，附英文・平假名・羅馬拼音

## 本機使用

直接開啟根目錄的 `index.html`，或用簡易伺服器（避免 `file://` 對語音／字型的限制）：

```bash
python3 -m http.server
```

再造訪 `http://localhost:8000`。

## 架構

每個子資料夾都是一個自成一體的 `index.html`：資料以 `DATA` 物件內嵌於 `<script>`，卡片式呈現，發音使用 `window.speechSynthesis`（ja-JP／zh-TW）。子資料夾之間沒有共用程式碼。每個單元另有各自獨立的 GitHub repo（`ch2`、`n1`–`n4`、`pat`、`part`、`te`、`adj`、`connecting`、`four`、`con`、`udemy`、`sentences` 等）；本 repo 為含首頁的整合版，首頁以 tab 分為 N5 入門／單字・漢字／文法專題／會話／課程筆記・例句五群，共 19 個學習頁面。
