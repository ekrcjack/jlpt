# 日本語學習 ｜ JLPT 單字・文法・發音

一組獨立、單檔的 HTML 日語學習應用，依 JLPT 程度串成一個總覽首頁。無需安裝或建置，直接用瀏覽器開啟即可；每個項目皆附例句、假名讀音、中文翻譯與 Web Speech API 發音朗讀。

## 線上瀏覽

首頁（`index.html`）以卡片連結到各程度的學習頁：

- **N5** — `ch2/`：單字漢字發音（五十音、必背單字、漢字、動詞、形容詞）
- **N4** — `n4/`：單字 386＋文法 118
- **N3** — `n3/`：單字 377＋文法 150
- **N2** — `n2/`：單字 400＋文法 147
- **N1** — `n1/`：單字 430＋文法 160

## 本機使用

直接開啟根目錄的 `index.html`，或用簡易伺服器（避免 `file://` 對語音／字型的限制）：

```bash
python3 -m http.server
```

再造訪 `http://localhost:8000`。

## 架構

每個子資料夾都是一個自成一體的 `index.html`：資料以 `DATA` 物件內嵌於 `<script>`，卡片式呈現，發音使用 `window.speechSynthesis`（ja-JP／zh-TW）。子資料夾之間沒有共用程式碼。各程度另有各自獨立的 GitHub repo（`ch2`、`n1`–`n4`）；本 repo 為含首頁的整合版，供 GitHub Pages 一站瀏覽。
