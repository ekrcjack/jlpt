# Quizlet 匯入檔

由 `index.html` 的 `DATA`（23 單元 / 219 場景 / 568 句對話）產生，每張卡片：

- **正面**：日文句　例：`やあ、陽子。元気？`
- **背面**：羅馬拼音／中譯（兩行）

## 匯入步驟

1. Quizlet → 建立學習集 → 「匯入」
2. 貼上檔案全文
3. 分隔符設定（**兩項都要改**）：
   - 詞彙與定義之間：**Tab**
   - 卡片之間：**自訂 → `@@`**

> 背面含換行，所以「卡片之間」不能用預設的「換行」。

## 檔案

- `all.txt` — 全部 **553 張**（568 句去除 15 句重複；同一句在不同單元出現時只留一張）
- `unit-01-問候.txt` … `unit-23-方便接話.txt` — 每單元一檔，共 23 檔，保留對話原始順序、不去重

一次匯一個檔，各建一個學習集。全部都在 Quizlet 單集 2,000 張上限內。
