名詞與な形容詞的丁寧否定另有一套「じゃありません／じゃありませんでした」，意思完全相同（第 31・32 課）。

「い」換成「かった」是常體過去否定的萬用規則：ない→なかった、くない→くなかった、じゃない→じゃなかった。

兩個要單獨背的例外：行(い)く → 行った（不是「行いた」）、いい → よかった（不是「いかった」）。

四格只動語尾，詞幹完全不動。

詞類 / 例字
RU44・47・48る動詞 食(た)べる吃
U45・48う動詞 帰(かえ)る回去、回家
U45・47う動詞 行(い)く去

四格只動語尾，前面的詞幹完全不變：ます → ません → ました → ませんでした。

過去否定＝「ません（否定）」＋「でした（過去）」，看到就直接拆成「沒有～」。

第 47 課教現在肯定／現在否定，第 48 課補上過去肯定／過去否定，兩課合起來才是完整的四格。

形容詞・名詞句（丁寧體）

い形容詞是「い」自己變；な形容詞與名詞則是後面的です在變 ─ 直排並列最看得出差別。

詞類 / 例字
い形容詞74い形容詞 面白(おもしろ)い有趣的
い形容詞76不規則 いい（良い）好的
い形容詞76不規則 かっこいい帥的
な形容詞75な形容詞 元気(げんき)な有精神的
な形容詞75な形容詞 便利(べんり)な方便的
名詞26・31・32名詞句 学生(がくせい)學生（じゃありません 系）
名詞47・48名詞句 日本(にほん)の映画(えいが)日本電影（じゃないです 系）

い形容詞是語尾自己變：ーいです → ーくないです → ーかったです → ーくなかったです。

な形容詞跟名詞一樣，變的是後面的です：です → じゃないです → でした → じゃなかったです（接です時語尾的「な」要拿掉）。

例外只有「いい」系：除了辭書形與現在肯定，第一個「い」全部變成「よ」。

名詞本身完全不變，變的是句尾。否定有兩套講法，意思一樣：じゃありません（第 31・32 課）與じゃないです（第 47・48 課）。

過去否定就是把否定形接上過去：じゃありません＋でした／じゃない＋かったです。

兩個要單獨背的例外：行(い)く → 行った（不是「行いた」）、いい → よかった（不是「いかった」）。

句型本身的四態

變的都是最後那個助動詞（いる／なる／です）；只有〜たい照い形容詞變。

詞類 / 例字
RU93〜ている（動作進行中）食(た)べている正在吃
い形容詞164〜たい（我想做）食(た)べたい想吃
RU166〜たがっている（看起來想做）飲(の)みたがっている看起來想喝
U166〜たがる 本身（不加いる）飲(の)みたがる想喝
名詞156〜つもりだ（打算做）行(い)くつもり打算去
U159〜なる（變成）暖(あたた)かくなる變暖

這些句型的四格，變的都是最後那個助動詞：いる → います／いません／いました／いませんでした，なる → なります／…，つもりだ 則跟名詞句一樣用 です／でした。

「〜たい」比較特別：它照い形容詞變化，所以否定是たくありません、過去是たかったです。

て形變化（接續形）

て形沒有時態，所以這張不排四格 — 左欄是變化規則，右欄是例字，點右欄即朗讀て形。

五段動詞口訣：う・つ・る → って ／ む・ぶ・ぬ → んで ／ く → いて ／ ぐ → いで ／ す → して。濁音（む・ぶ・ぬ・ぐ）跟著濁音走，其餘都是清音。

一句話記完四類：只有動詞和い形容詞要「變形」，な形容詞與名詞只要「加で」（で 就是 です 的中止形）。

外型像一段、其實是五段的陷阱字：切(き)る・帰(かえ)る・入(はい)る・走(はし)る・要(い)る・知(し)る → 切って・帰って・入って・走って。

兩個必背例外：行(い)く → 行って、いい → よくて。

て形本身沒有時態，時態一律由句尾決定：安くて美味しいです（現在）／安くて美味しかったです（過去）。

學會就能解鎖：〜てください（請～）／〜ています（正在～）／〜てもいいです（可以～）／〜てはいけません（不可以～）／〜てから（～之後）／〜て、〜（動作接續）。

⚠️ 同一句可能出現兩個「で」，功能不同：
「彼は先生で、学校で働いています。」前者＝名詞的接續形，後者＝場所助詞。で 前面是身分・性質→接續；場所・工具・手段→助詞。

short form ＝ 常體（普通形）：對朋友、家人、寫日記時用。它同時是很多句型的必要接續形 ─ 〜と思(おも)います／〜と言(い)いました（第 117 課）、〜ないでください（第 119 課）、〜のが好(す)きです（第 120 課）、〜ので（第 144 課）、〜つもりだ（第 156 課）、〜でしょう（第 186 課）前面接的都是 short form。

動詞的四態全部從辭書形長出來，順序固定：辭書形 → ない形 → た形 → なかった形。所以第一步永遠是先確定它是五段還是一段。

五段／一段的判斷：辭書形不是「～る」結尾 → 一定五段；是「～る」而る前面是 a・u・o 段（ある・作(つく)る・乗(の)る）→ 五段；る前面是 i・e 段 → 多半一段（見(み)る・食(た)べる）。⚠️ 陷阱字 切(き)る・帰(かえ)る・入(はい)る・走(はし)る・知(し)る・要(い)る 長得像一段，其實是五段。

な形容詞・名詞的「だ」在口語常被省略：「静(しず)か？」「学生(がくせい)？」都很自然；但接 と思(おも)う・らしい 時不能省 ─ 「学生(がくせい)だと思(おも)う」。

⚠️ 別把た形和ます形的過去搞混：丁寧體是 食(た)べました，常體是 食(た)べた；同一個句尾只能選一種。
